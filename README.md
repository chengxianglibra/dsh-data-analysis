# DSH Data Analysis

在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 中，用自然语言完成数据分析，
浏览和复用业务指标定义，并将结果整理为可交互、可离线阅读的图表、报告和看板。
语义分析能力由 [Marivo](https://github.com/chengxianglibra/marivo) 提供；本地文件也可直接使用 pandas 或 DuckDB。

本项目是个人维护的社区插件，并非 DeepSeek 官方发行或维护的软件。

## 安装

### 环境准备

- Node.js `^22.19.0 || >=24.0.0`，与 DeepSeek Harness 一致：22.x 需至少 22.19.0，或使用 24.0.0 及以上版本；不支持 23.x。
- 本地开发与发布构建使用 Node.js 22.19.0；使用 nvm 时可在仓库根目录执行 `nvm install && nvm use`，读取 `.nvmrc`。
- 已安装并配置好 DeepSeek Harness `^0.1.5-alpha.1`（当前实际验收版本为 `0.1.5-alpha.1`）。
- `pnpm` 可在命令行中使用，供 Harness 安装插件。
- 已安装 Python 3.10+，命令行可运行 `python3`（Windows 为 `python`），且支持 `venv`/`ensurepip`；部分 Linux 发行版需额外安装 `python3-venv`。

默认安装方式会在首次启动时使用本机 Python 创建独立的虚拟环境，并通过 pip 安装 Marivo，无需预装 Marivo 或 uv。
首次启动需要联网下载依赖，请等待环境准备完成。

### 安装并启动

将插件安装到 Web Profile：

```bash
dsh plugin --profile web add @chengxianglibra/dsh-data-analysis
```

安装后启动 Web Profile；如果已在运行，请先退出再重新启动：

```bash
dsh --profile web
```

在 Web 界面选择分析使用的工作区（Workspace），新建会话并发送一条消息。
会话标题旁按顺序显示“数据源”“语义层”“报告”三个入口，浏览页面在原生右侧标签页打开。本文以 Web 界面为例。

### 本地文件分析

上传文件后直接提问，或指定 Workspace 中已有文件。助手可在插件绑定的 Python 环境中使用 pandas
或原生 DuckDB 分析 CSV、JSON、Parquet，无需先配置数据源或建立语义模型；需要时可继续生成报告。
默认安装包含 Marivo 的 `duckdb` extra（同时保留 `trino`、`clickhouse`）。Excel `.xlsx` 通过 DuckDB 的
[excel 扩展](https://duckdb.org/docs/stable/core_extensions/excel.html)读取；首次使用需要联网下载扩展，
并允许写入 DuckDB 扩展缓存。它不是额外的 Python 包，无需为此安装 `openpyxl`。
旧版 `.xls` 不在该扩展支持范围内，需要先转换为 `.xlsx`、CSV 或 Parquet。

纯文件分析无需经过 Marivo `md.raw_sql`。下面的数据源配置流程适用于数据库连接和需要复用的 Marivo 数据源。

## 能力

| 你想做什么 | 插件提供的能力 |
| --- | --- |
| 回答业务问题 | 用自然语言提出问题，分析指标趋势、比较不同时间或业务分组、探索变化原因 |
| 分析本地文件 | 复用原生附件路径，以 pandas 或 DuckDB 直接计算，并按需交付图表或报告 |
| 连接数据 | 配置数据源、管理连接凭证并测试连接；默认包含 DuckDB、Trino、ClickHouse 支持 |
| 统一分析口径 | 与 Agent 一起整理和复用指标、维度等业务定义，浏览语义对象及其关系 |
| 明确分析对象 | 在输入框通过 `@` 搜索并引用已有语义对象 |
| 展示分析结果 | 生成包含文字、指标卡、图表、表格和来源说明的报告或看板 |
| 阅读与分享 | 交互筛选、调整呈现、保存版本，并下载 HTML 离线阅读 |

## 如何使用

### 1. 准备数据源

在会话标题旁打开“数据源”，查看所属工作区的连接属性与配置状态：

1. 点击“新增数据源”，选择引擎，按表单填写名称及连接信息。
2. 如果需要身份认证，在同一表单的“连接凭证”中直接填写用户名、密码或令牌。
3. 测试连接，根据结果检查地址、凭证或访问权限。

凭证引用名自动生成，可展开“凭证引用名 · 确认或修改”查看和调整；也可填写已有引用，并将值留空以复用凭证。
编辑时已保存的凭证值不回显，留空沿用；填写新值默认使用新的引用，不删除旧的共享凭证。
手动指定已存在的引用并填写新值时，不会自动覆盖，需到凭证页确认更新。
已有数据源可点击“编辑配置”修改连接信息，名称和引擎保持不变；保存后重新测试。

管理员可在 Harness 当前 profile 的本插件配置项下设置 `datasourceDefaults`，按引擎类型为新建表单填入默认值：

```yaml
datasourceDefaults:
  trino:
    host: trino.internal.example
    port: 443
```

这是插件配置片段，随 Harness 现有配置加载机制生效；不是独立配置文件。未指定的字段保持原样，用户可修改或清空填充值；
切换引擎时清空表单并应用目标引擎的默认值。编辑或复用已有数据源不应用这些默认值。
只配置非敏感普通字段，不能设置 `*_env` 凭据引用或凭据值；内部地址只保存在部署环境的配置中，不必加入插件源码。
打开新建表单时按当前 Runtime 校验引擎、字段和类型，错误会明确显示且不回显配置值；配置错误不阻止已有数据源编辑。

分析需要新增或修复数据源时，助手可自动打开所属会话的右侧配置页。填写后点击“保存并测试，成功后继续”；
缺少凭证时继续在凭证表单补齐，测试成功后原调用返回，助手再核验目标表并继续分析。
请求页默认显示新增表单；切换“使用已有数据源”后，可选择已有连接并验证，无需重复创建。测试失败保留已保存的配置，允许修正后重试；取消请求不会作为成功继续。
请通过凭证表单提交密码或令牌，不要粘贴到聊天消息中。

### 2. 用自然语言提出分析问题

说明使用哪些数据、时间范围、指标口径和希望得到的结果。例如：

> 使用订单数据，分析 2026 年 8 月的销售额和订单量，与 7 月比较，按渠道拆分，并说明数据来源和口径。

> 检查最近七天的查询耗时，找出耗时最高的查询类型，给出趋势图和明细表。

如果还没有整理业务定义，可以先让 Agent 帮助梳理：

> 先查看当前数据源中有哪些订单相关表，和我确认销售额、支付订单数的统计口径，再保存为可复用的业务定义。

需要报告时，直接说明希望的内容：

> 将这次分析整理为一份报告，包含结论、关键指标、趋势图、渠道对比表和来源说明，并提供可下载的 HTML。

### 3. 浏览和引用业务定义

点击会话标题旁的“语义层”，按分类或关键词查找指标、维度等对象，查看业务定义和对象关系。
这里展示已有定义；浏览页面不会执行分析查询。浏览页固定属于入口所在会话的工作区，支持把语义对象独立打开。

在聊天输入框输入 `@` 可搜索并选择当前工作区的对象；多词搜索可输入 `@"monthly revenue"`。
选中后将显示完整的 `kind:path` 引用，便于 Agent 使用你指定的对象开展分析。

### 4. 阅读、调整和追问报告

当前会话交付新报告后，右侧自动打开该次交付的固定版本；后台完成、历史回放和重连不会抢占阅读页面。
同工作区的后台交付会更新已打开的报告目录，并在 current 页提示新版本，保留正在阅读的内容。
报告生成后自动在右侧 tab 打开固定版本，主对话不附加报告 block。默认只保存 JSON，点击下载时才生成 HTML。“报告”目录按标题查找并打开 current；可以并排阅读不同报告和版本。
发现新版本时 current 先提示，点击刷新或重新打开才切换，旧版本筛选随切换重置。
没有活动会话时，侧栏的“报告”入口仍可阅读 Workspace 中的报告。

- **探索数据**：筛选图表和表格，调整支持的图形及展示字段。交互使用报告中已保存的数据；获取新数据或重新计算时，在会话中提出要求。
- **查看来源**：查看报告内容附带的来源信息，核对分析依据。
- **调整呈现**：从 current 页点击“编辑报告”，在原编辑窗口编辑标题、正文、指标标签和图表／表格配置，移动或删除内容，支持撤销、重做和保存。
- **继续追问**：在支持的报告内容菜单中选择“Ask DSH”，将相关上下文带回输入框，补充问题后发送。
- **查看历史**：保存编辑后可在历史侧栏查看和下载已保存的版本，历史版本只读。

页面筛选不会重新计算指标卡，也不会写入保存的报告。希望保留当前筛选结果时，使用“导出当前视图”。

### 5. 下载与分享

报告右上角的导出菜单提供两种方式：

| 选项 | 适合的用途 |
| --- | --- |
| 下载完整报告 | 下载所查看版本的完整 HTML 报告，供离线阅读 |
| 导出当前视图 | 将当前筛选、图形和表格排序固定为 HTML，附带来源版本及导出时间，分享当前看到的内容 |

编辑模式下，请先保存或取消编辑再导出。下载的文件可直接用浏览器打开。

## 报告发布到对象存储

通过 `reportPublishing.enabled` 开启 S3 兼容对象存储发布；在“数据源与凭证”管理独立 AK/SK 和可选 Token。开启后报告菜单的完整 HTML 与当前视图下载均替换为发布，成功返回链接。配置示例与边界见[报告 HTML 发布](docs/modules/report-publishing.md)。
