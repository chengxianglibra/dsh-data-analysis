# 0.1.2

本版将分析展示统一为可编辑报告与自包含 HTML，新增语义对象浏览和引用输入，完善数据源创建、凭据管理与单次 Python 执行。

## 新增

- `marivo_present` 从 Draft 生成报告、JSON 和离线 HTML，并在对话中提供打开、下载入口。共享 reader 支持 Markdown、精确数值表格、18 类图表、KPI 比较卡片及作者声明的全局筛选；图表探索和筛选使用已有数据。
- 报告支持在线编辑、移动和删除内容、撤销／重做，以及同一 Report 的新 build 保存。Agent 可通过 `report_id` 与 `expected_build_id` 更新已有报告；并发版本冲突明确报错。
- 在线报告的 **Ask DSH** 将当前内容、图表探索与筛选上下文追加到原会话草稿，保留已有文字、引用和附件，不自动发送。离线 HTML 提供复制上下文。
- 会话标题旁提供“语义层”和“数据源与凭证”。语义层支持分类搜索、定义详情、关系浏览及报告来源跳转，仅读取 Catalog 元数据；输入框支持通过 `@` 选择精确语义引用。
- 数据源管理支持从当前 Marivo 公开配置创建数据源、查看连接属性、配置凭据和测试连接。`marivo_python` 在本次调用中完成凭据准备与执行；Web 补齐凭据并测试成功后可继续原调用。
- 新增 `dsh-data-analysis-presentation` Skill、Python `write_dataset` helper 和 `dsh-data-analysis-presentation-lint` 静态预检命令。computed 数据可使用独立展示标签，并保留 int64／Decimal 精度。

## 修复与改进

- 完成后的报告卡片保持在最终回复旁；重新打开原卡片可读取同一报告最近保存的结果。
- 改进宽屏、窄屏、KPI 排列和图表布局；HTML 支持离线交互、无脚本阅读和打印。
- 来源页面展示保存的 Python／SQL 代码与精确数据，支持格式化和高亮；明确区分历史来源快照与当前语义定义。
- 数据集写入及 int64 校验错误提供字段、位置、原因和修复提示；数据源创建保留非法凭据引用的具体诊断。
- 共享 Runtime 校验随包 presentation-kit 的实际版本，避免插件更新后继续复用旧 helper。

## 兼容性与升级

- 要求 **Node.js 24+**、**DeepSeek Harness `0.1.1-rc.2`**；Marivo 精确升级为 **`0.5.4`**，安装约束为 `marivo[duckdb,trino,clickhouse]==0.5.4`。随包 presentation-kit 为 **`1.1.0`**，Runtime marker 为 `dsh-data-analysis-runtime/v3`。
- 插件管理的旧 Runtime 会先保留诊断备份，再按新版本要求重建；使用自定义 `pythonExecutable` 时，管理员须安装匹配的 Marivo 与随包 presentation-kit，否则启动会明确报错。
- **展示接口有破坏性变化**：移除旧 report-kit、`dsh-data-analysis-report` Skill、经典 JavaScript 资源、`marivo_report_render`、`marivo_evidence_sources` 与 `./evidence` export。新展示使用 `dsh-data-analysis-presentation` 和 `marivo_present`；需要读取 Evidence 时使用 Marivo 公共 API。
- **执行接口有破坏性变化**：移除 `marivo_datasource_access` 及跨调用 Shell lease 接口。依赖旧 prelude 的分析调用应改为 `marivo_python({ code, datasources })`，声明本次执行访问的全部精确数据源名称。
- 生成文档、receipt 和 delivery 使用 **schema v2**；Draft 与 typed dataset 保持 **v1**。旧报告不读取、不自动迁移，旧文件保留；需使用新 Draft 重新生成。已生成 HTML 保留生成时的内容与样式。
