# 报告通用展示优化验收

## 范围与责任

本次只修改插件共享 reader、样式、相关验证及文档。保留作者正文、结论、字段标签、block 顺序、
数据值、来源事实与文档 identity，不作解释性改写，不重新查询、observe、revalidate 或读取凭据。
Marivo 继续拥有分析事实，Harness 继续拥有 Workspace 与交付生命周期。

参考 Data Analytics 报告的单列阅读、弱边框和来源弹窗，最终展示行为为：

- 中性浅深色、中文排版、相邻 metric 自适应布局、精确数字千分位、带 UTC 标识的生成时间。
- Markdown 保留 `h2` 章节层级，只有作者 `h1` 降为 `h2`，报告标题独占页面 `h1`；不修改文本。
- cell 右上角三点菜单打开数据源 modal，按“概要 / 数据预览”组织；没有数据集时只显示概要。
- 概要保留实际指标或字段、数据集、报告生成时间、已有语义路径、来源创建时间、实际问题及不可用原因。
  隐藏技术 ID、原始 JSON、空事实、成功检查和通用声明；不增加缺乏真实数据的 SQL、表名或筛选条件。
- 数据预览保留精确值、排序和分页，chart 仅显示其绑定列；图表下方不再保留“查看数据”入口。
- “继续分析”和独立复制图标改为三点菜单内的“复制上下文”，范围仅为当前 cell；复制失败可使用手动复制弹窗。
- 来源不可用、截断、近似绘图保留简短状态，移除重复页首声明和历史定义缺失提示。
- 无脚本使用原生 `details` 查看精简来源；打印显示来源概要和精确表格，隐藏交互控件。

没有修改已有交付目录、profile 或运行服务。更新 reader 需要通过后续插件重装进入实际服务；
已交付 HTML 是独立快照，不会随源码自动变化。静态图形继续使用精确表格，没有增加静态 SVG。

## 原文档不变性

对用户指定报告的 `presentation.json` 调用纯 `buildPresentation(document)`，确认新 HTML 内嵌的
完整文档与输入逐字段相等，不写回原报告，不创建新 receipt，也不重新读取来源。
原文档的 9 个来源在新静态 reader 中各出现一次，其内容、引用和数据均未改变。

本地检查摘要：`/tmp/dsh-presentation-style-preview/equality.json`。该目录可能被系统清理。
浏览器未访问原报告：此前直接打开其 `file://` URL 被策略拒绝，因此没有通过其他地址绕过访问。

## 图表样式复核

进一步对照已安装 Data Analytics 0.2.10 的 `src/analytics-app/charting/ChartRenderer.tsx`、
`chart-tokens.css` 及 `src/analytics-app/styles.css` 的 report panel 后置样式，
采用无外框、320px 图高、自动 Y 轴宽度、竖向 Y 标题、底部 X 标题、极浅水平实线网格、
monotone 折线和底部图例。连续折线不显示常驻圆点，孤立观测保留可见点，null 不连线。
当前契约仅支持 line/bar；pie、area、scatter、横向 bar 的拒绝行为未改变。

新增独立合成图表页，通过 CUA 检查 24 点折线、全负柱、单类别柱、正负混合柱、null 孤立点和精确小数：

- 820px 宽折线绘图区实际宽 741px；Y 标题竖排且贴近左侧，额外轴线和连续序列圆点数量均为 0。
- 刻度显示 `50,000 / 10万 / 15万 / 20万`；375px 下保留 `00:00 / 06:00 / 12:00 / 23:00`，不重叠。
- 全负柱 `[-0.05, -0.01]` 的实际高度为 220px 和 44px，共同从零向下延伸；单类别柱宽 48px。
- 正负混合柱以同一条零参考线为基准；null 两侧两个孤立观测仍有圆点，连续段没有多余圆点。
- 375px 下六个图表的轴标题和刻度均在图表边界内，页面 clientWidth/scrollWidth 均为 360px。
- 深色模式下实际检查折线、负值柱、网格和轴文字；数据预览继续显示完整长标签及 `0.1000 / 0.2500` 原值。

保留生产契约、投影、数据排序、精确值、单位和原始 block，未增加分析类型或改变业务内容。

## 表格对齐复核

数值列的 th/td 统一右对齐，日期与文本列统一左对齐；排序箭头独立定位，不挤占表头文字宽度。
表格 caption 与第一列内容使用相同水平内边距；打印时同步缩为 5px。
CUA 实测正文三个列标签与数据边缘差值均为 0px，排序后仍为 0px；375px 数据预览没有页面横向溢出，
静态打印的表头与数据对齐一致。排序、分页及原始值不变。
