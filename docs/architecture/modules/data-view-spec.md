# 数据视图统一规格

## 范围与归属

本规格约束 AnalysisFrameView 与 DatasetView 的结果卡片、图形、表格和左下角弹窗的视觉与信息放置。
视图选择仍由 `resolveFrameView` / `resolveDatasetView` 决定，行为契约见[分析文档 reader](presentation-reader.md)；
基础控件、主题桥接与弹层生命周期见[插件私有 UI 组件](custom-ui-components.md)。
本规格是两类数据视图的目标视觉契约，实现逐步迁移；尚未迁移的部分以当前代码为准。

组件只展示快照中已保存的事实。规格不引入新的计算、推断或文案来源；快照中没有的语义不显示。

## 色彩

数据色、方向色和状态色是三组独立 token，互不替代。Frame / Dataset 卡片不得用业务状态色覆盖 `--chart-*`。

| Token | 值（明暗相同） | 用途 |
| --- | --- | --- |
| `--chart-1` | `oklch(0.623 0.214 255)` | 第一系列、本期、单系列图 |
| `--chart-2` | `oklch(0.70 0.13 180)` | 第二系列 |
| `--chart-3` | `oklch(0.76 0.15 70)` | 第三系列 |
| `--chart-4` | `oklch(0.62 0.19 295)` | 第四系列 |
| `--chart-5` | `oklch(0.60 0.20 350)` | 第五系列 |
| `--chart-6` | `oklch(0.62 0.16 45)` | 第六系列 |
| `--chart-7` | `oklch(0.65 0.15 125)` | 第七系列 |
| `--chart-8` | `oklch(0.55 0.08 260)` | 第八系列 |
| `--mv-baseline` | `oklch(0.705 0.015 265)` | 基期、对照端、瀑布起点 |
| `--mv-up` | `oklch(0.60 0.20 25)` | 已保存差值为正 |
| `--mv-down` | `oklch(0.56 0.13 155)` | 已保存差值为负 |
| `--mv-quality` | `oklch(0.76 0.15 70)` | 质量比率细条、不完整期斜线 |
| `--chart-grid` | 前景色 10% 混合透明 | 网格线 |

- 方向色只表示已保存差值的符号：涨为红、跌为绿，零值用前景色。插件不判断变化的好坏，不因指标含义翻转颜色。
- `--mv-quality` 与 `--chart-3` 同色，因此质量状态总是配合形状出现（细条、斜线、部分圆环），不单靠颜色。
- 系列按 `--chart-1..8` 顺序分配；顺序跟随保存的 series 顺序，不按数值重排。热力图色阶为 `--chart-1` 与卡片背景的 5 级混合（8% → 96%）。

## 卡片与标题行

- 卡片：圆角与边框沿用 radix-nova Card（`rounded-xl`、1px ring），内边距由 `--card-spacing: 18px` 决定。
- 标题行从左到右为：标题（14px / 600）、上下文、整组件提问按钮。插件不生成副标题、定义、说明句或语义标签行；
  报告作者写入的 `display.subtitle` 作为标题下的单行次要文本显示。
- 上下文最多一项，11px 次要色：比较端点（`2025-06 ⇄ 2025-05`）、固定时间范围、或日历粒度与期数。Dataset 只显示保存行的形状（如 `260 行`、`6 × 6`）。
- 影响解读的状态以短标签跟在上下文后，例如“受限范围”“2,880 / 4,008 行”“筛选 12 / 260”，不写整句。
- 左下角图标行依次为数据、覆盖、期间对应、语义来源、Python；图标行与内容之间不加分隔线。

## 语义放置

第一眼需要的信息放进图形，其余放进左下角弹窗。

| 信息 | 放置位置 |
| --- | --- |
| 值名 | 标题、图例、指标块标签 |
| 单位（`column.unit`） | 轴标题、指标块数值后缀、图例标签 |
| 聚合（仅 `statistic` 与 `pair_statistic`） | 轴标题前缀与图例标签：`sum` → Σ，`mean` → μ，`row_count` → #，`pair_count` → n |
| 期间端点、日历粒度 | 标题行上下文；时间轴悬停时 x 轴上的期间胶囊 |
| 色阶范围 | 热力图右下 5 级色条两端的已绘制最小值、最大值 |
| 相关系数与配对数 | 系数标尺下的统计行：`r −0.2582`（spearman 用 `ρ`）与 `n 258` |
| 时区、期间 label 对应、选择与 cutoff | 期间对应弹窗 |
| 度量路径、维度、数据源、实体、固定轴、`rowScope`、groups | 语义来源弹窗 |
| 捕获行数、总行数、捕获时间 | 覆盖弹窗；未完整捕获时覆盖图标显示部分圆环 |

observation 值没有已保存的聚合事实，不显示聚合符号。Dataset 没有分析语义，不显示聚合符号、期间或语义来源。

## 图形标记

- 网格：只画水平线，虚线 `3 4`，颜色 `--chart-grid`；横向柱图只画垂直线。
- 刻度：10.5px 次要色，等宽数字。轴标题写在 y 轴左上角，形如 `Σ 行程量`、`平均票价 USD`。
- 折线：2px，monotone 曲线；面积在线下填充，透明度 0.26 → 0 的渐变。
- 柱：宽度为 band 的 0.62，顶部圆角 2–4px；类别轴等距排布。
- 不同单位的时间序列按单位分面并共享 x 轴，不叠加第二 y 轴，不缩放保存值。
- 热力图单元格间距 2px、圆角 2px；单元格数量适中时可在格内标注格式化值，深色格用白字。
- 横向排行：行标签固定宽度，超长时截断并以悬停提示显示全名；第二个度量以右侧数值列呈现，不画位置无意义的标记。
- 环形占比：活跃扇区外扩 4px，其余 0.38 透明度；极小份额显示 `<0.1%`。堆叠条间隔 2px。
- 瀑布：起点用 `--mv-baseline`，终点用 `--chart-1`，贡献按方向色，连接线为 `2 3` 虚线。分解明细显示全部已保存成员，不折叠为“其他”。
- 哑铃：本期实心点、基期空心点（`--mv-baseline` 描边），连线为次要色，行尾标注已保存差值；没有差值字段时不标注。
- 相关：保存的是系数而非原始配对，因此在固定的 [-1, 1] 标尺上标记系数，不画散点或拟合线。

## 状态编码

| 状态 | 编码 |
| --- | --- |
| 不完整期 | 柱：所属系列 22% 底色加 `--mv-quality` 斜线；线：空心点 |
| 缺失值 / NA | 断开路径；表格中次要色斜体 `NA`；不补零 |
| 零值 | 1px 细线或零值标记，与缺失区分 |
| 缺席端点 | 只显示存在的一端，不画连线 |
| 结构性占比 | 只显示数字 |
| 质量比率 | 数字下方 4px `--mv-quality` 细条 |

## 交互

- 悬停：活跃元素保持原色，其余降至 0.3 透明度，不换色。热力图保留所在行和列。
- 时间轴悬停显示前景色渐变十字线和 x 轴期间胶囊。
- 提示框：首行为期间或类别标签，其后每行为色块、值名和格式化的保存值；不显示由绘图数据现算的占比、均值或差值。
- 选点后的“就此提问”与整组件提问沿用 reader 契约。

## 表格与弹窗

- 表头：列名后跟紧凑类型（`str`、`i64`、`f64`）、聚合符号和单位，次要色等宽小字。数值右对齐、等宽数字。
- 悬停行用 `--muted` 背景；排序状态以表头上方的短标签显示。分页只显示 `1–8 / 260` 与前后按钮。
- 弹窗：圆角 14px，共用 DetailsDialog 外壳。语义来源弹窗依次为属性块（度量、聚合、单位、期间、范围）、出处列表、状态标签。
- 不可用状态：图标、一行原因与一行后续动作；不用空表格或“0 项”代替。
- 弹窗内不写说明计算过程、方法参数或界面含义的段落。

## 文本约束

数据、颜色和布局承担解释。卡片与弹窗不出现复述图种、数值或规则的说明句；必要状态使用短标签。
标签文案遵循 locale 词典，业务名称、字段标识、单位和精确值不翻译。
