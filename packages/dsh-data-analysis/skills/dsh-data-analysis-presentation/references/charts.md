# 图形配置与数值表达

当前支持 `line`、`bar` 和表格。折线表达已有顺序上的变化；柱形比较类别；复杂、稀疏或无法可靠绘图的数据使用表格。其他图形需要用户接受受支持的表达，不能写入未经支持的图形名称。

`x` 指定一列，`y` 列出已有数值列，系列名称与单位来自 dataset 的列描述。reader 按给定数据组织系列，不为问题计算 aggregate、筛选、排序或补零。时间序列应先在分析中确定顺序和粒度；markdown 说明时间范围、单位与比较方向。没有 chart title 字段，标题用相邻 markdown。

## 数值模式

- `numericMode: "exact"` 适用于 float64 和 JS 安全整数范围的 int64。decimal 即使看起来很小，也不能使用 exact 绘图。
- decimal 或超出 JS 安全整数范围的 int64，要么只用保留原值的表格，要么显式选择 `approximate` 绘图并保留精确值表格。近似值仍必须能转换为有限数；不要把近似几何位置称为精确数据。
- null 是缺失值，不是 0；空 dataset 可展示空图/表，不生成引用不存在行的 metric。

同一轴上的系列应有可比较的含义和单位。没有双轴或前端换算字段，不同单位可拆图或表格。`approximate` 仅将图形坐标转换为近似数值；tooltip 和精确数据表始终保留原始值，包括 int64/decimal 的原始文本。

## 最小组织

单图通常只需简短说明、一个 chart，必要时附表。多图共享同一份 dataset 时复用 `datasetId`；每个 block 使用独立 `id`。reader 自动关联 dataset 的来源面板；额外 source block 适用于集中讨论来源或只读来源的任务。

相关完整示例见 [examples.md](examples.md)。可交互功能限于当前快照的表格排序/分页、系列显隐和复制追问上下文，不代表全量数据筛选或自动刷新。
